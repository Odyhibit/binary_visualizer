# Contributing

Changes should follow this workflow:

1. Create or reference a GitHub issue.
2. Create a short-lived branch for the change.
3. For agent-created branches, use the naming convention `agent/<issue-number>-<description>`.
4. Make focused commits.
5. Open a pull request against `main`.
6. Resolve review comments and CI failures.
7. Squash merge the pull request after review.

Direct changes to `main` should be avoided.
